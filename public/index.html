Frequently Asked Questions about Discord Server Cloning

Cloning a Discord server with Discloner takes just 3 straightforward steps:

  1. 1. Enter Authorization Token: Provide your Discord user token with administrative access to both the source server (to read structure) and the target server (to create roles and channels).
  2. 2. Select Source & Target Guild IDs: Paste or search the Server IDs for your source server (the template to copy) and your empty target destination server.
  3. 3. Configure & Start Migration: Customize what you wish to replicate (roles, permissions, channels, emojis, stickers, or message history) and click Start Server Migration to begin the automated real-time cloning process.

Yes, security and privacy are top priorities. Discloner is built with strict privacy guarantees:

  • Zero Token Storage: Your Discord user authorization token is processed strictly in-memory for the active session and is never persisted to databases or written to disk.
  • Automatic Redaction: All live log streams and debug telemetry automatically mask token strings and sensitive authentication headers.
  • Anti-Ban Rate Limiting: Built-in rate limiting adheres to Discord API guidelines with jittered exponential backoff, preventing spam flags or API account blocks.

Yes, with customizable tuning. While standard Discord API bot endpoints do not allow impersonating original timestamps or user accounts directly, Discloner implements an advanced Webhook Mimicry Engine:

  • Webhook Re-creation: Temporary high-speed webhooks are provisioned in target channels to re-post messages matching original author avatars and display names.
  • Configurable Limits & Delay: You can tune the message limit per channel (e.g., 5 to 100 messages) and set millisecond delay pacing to stay well below webhook rate limits.
  • Attachment Transfers: Image and media attachments are securely transferred to preserve context across cloned conversations.

By default, Discloner features a safe Target Server Cleanup option:

  • When Target Server Cleanup is enabled (recommended for empty destination servers), existing default channels, roles, and emojis on the target server are pruned before creating the clean clone.
  • If you prefer to append new channels without deleting existing assets, simply toggle the cleanup setting off in the options panel.

Migration Guide & Setup

1

Enable Developer Mode in Discord

Go to Discord Settings → Advanced → Toggle Developer Mode ON. This allows you to right-click servers and copy their 17–20 digit Snowflake ID.

2

Account Permissions

Your Discord account must have Administrator or Manage Server / Manage Roles / Manage Channels permissions on the target server.

3

Message Synchronization (Optional)

Message cloning is OFF by default. If enabled in Advanced Settings, messages are replicated using Discord webhooks with original author names and avatars.
